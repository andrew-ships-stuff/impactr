# Installation

Impactr is a Go CLI. The repository currently documents Homebrew and `go install` paths.

## Current source install

```bash
go install github.com/andrew-ships-stuff/impactr/cmd/impactr@latest
impactr --version
```

The organization is `andrew-ships-stuff`; commands using `andrew-ships-code` do not match the repository. A Homebrew tap exists, but it does not yet contain an Impactr formula. Homebrew installation is planned for the first packaged release.

## Build from source

Impactr currently requires Go 1.26.0 or newer.

```bash
git clone https://github.com/andrew-ships-stuff/impactr.git
cd impactr
make install
```

`make test` runs the offline suite. `make run` analyzes `HEAD` against `master`; use `BASE`, `HEAD`, and `IMPACTR_ARGS` to override it.

## Install the embedded model

```bash
impactr model install
```

Model installation is a separate consent boundary. Impactr shows the model name, license, size, and checksum before downloading. A partial file is only promoted into the cache after verification.

## Offline operation

Once the binary and optional model are present, local analysis does not require a hosted service. Use `--no-ai` or provider `none` when deterministic output alone is preferred.
