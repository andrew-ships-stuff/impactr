# Impactr documentation

Impactr compares Git states, builds evidence-backed architecture graphs, calculates a bounded blast radius, renders reviewable artifacts, and can explain those facts with a CPU-only embedded model.

Use this documentation to get from installation to a local analysis, then connect the same deterministic engine to Git hooks, GitHub Actions, or GitLab CI.

## Start with a local analysis

```bash
go install github.com/andrew-ships-stuff/impactr/cmd/impactr@latest
cd your-repository
impactr analyze --no-ai
```

The Homebrew formula is not published yet. The site will switch the primary command after the first release is available in the tap.

The command compares your branch against the merge base of the discovered default branch. Artifacts are written to `.impactr/`.

## The reliability contract

Impactr treats the deterministic graph as the source of truth. Inference receives compact changed facts and bounded affected-node IDs, not full repository files. Claims without valid graph evidence IDs are discarded. Provider failure does not invalidate deterministic analysis.

> Affected means reachable through configured dependency relationships. It does not mean a runtime failure is guaranteed.
